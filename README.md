# Избушка дизайна — сайт Андрея Хола

Сайт-витрина работ в концепции «Свет в окне»: тёплая мастерская внутри технологичного стеклянного куба.
Палитра «сумерки»: тёплый графит, янтарь окна, крафт, сепия и холодные блики стекла.

## Что уже сделано (блоки 0–4)

0. **Прелоадер**: избушка прорисовывается линиями, загорается окно, собирается рамка куба.
1. **Порог**: 3D-куб с медальоном избушки поворачивается за курсором, вокруг летают карандаши и светятся орбиты. На фоне гравюрные линии, которые проявляются тёплым светом под курсором-фонарём и рассыпают искры.
2. **Бегущая строка**: две ленты навыков, скорость зависит от скролла.
3. **Обо мне**: светящееся окно под фото, текст проявляется по словам при скролле, счётчики.
4. **Карта навыков**: бенто-сетка направлений, у каждой плитки свой фонарь, наклон и микро-анимация иконки.

## Без персональных данных (152-ФЗ)

Сайт полностью статический: нет форм, аналитики, cookie и встроенных виджетов.
Шрифты (Unbounded, Cormorant Garamond, Manrope, лицензия SIL OFL) лежат в `assets/fonts`, сторонних запросов нет.
Это закреплено политикой безопасности (CSP) в `index.html` и `netlify.toml`.

## Запуск локально

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Netlify

Сборка не нужна. Подключите репозиторий, а Netlify возьмёт настройки из `netlify.toml` (публикуется корень репозитория).
